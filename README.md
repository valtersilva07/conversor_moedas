# 💱 Conversor de Moedas em Java

Este é um projeto simples de **conversor de moedas** desenvolvido em Java. Ele utiliza a [ExchangeRate-API](https://www.exchangerate-api.com/) para obter as taxas de câmbio em tempo real.

---

## 🚀 Funcionalidades

- Escolha da moeda de origem e destino a partir de uma lista
- Conversão de qualquer valor com taxas reais
- Repetição de múltiplas conversões
- Integração com API externa usando `HttpClient`
- Leitura de JSON com a biblioteca `Gson`
